01START WITH A CLASS

Mark what Casper can call.

@export_contract selects a class for Wasm exports. Each @entry_point method becomes callable through its typed ABI. Ordinary methods remain ordinary Python.

contracts/flipper.py · class excerpt
from casthon.contract_api.runtime import named_keys
from casthon.contracts import Contract, entry_point, export_contract

@export_contract
class Flipper(Contract):
    value: bool = named_keys.property()

    @entry_point
    def flip(self) -> None:
        self.value = not self.value

    @entry_point
    def get(self) -> bool:
        return self.value

Method markerRegisters the callable entry point.
Plain PythonDirect calls still work in tests.

02KEEP STATE

Declare a field. Read it like a field.

Counter keeps one total and one per-account tally. This is its complete class: the fields declare persistent storage, the constructor supplies the initial total, and the entry points control who can change or read it.

contracts/counter.py · complete Counter class
from typing import Any

from casthon import AccountHash, Dictionary, U32
from casthon.contract_api.runtime import get_caller, named_keys
from casthon.contracts import entry_point, export_contract
from contracts.pausable import Pausable, require_unpaused

def _account_key(account: AccountHash) -> str:
    return bytes(account)[1:].hex()

@export_contract
class Counter(Pausable):
    count: U32 = named_keys.property()
    increments: Dictionary[AccountHash, U32] = named_keys.property(key=_account_key)

    def __init__(self, initial: U32 = 0, **state: Any) -> None:
        super().__init__(count=initial, **state)

    def _increment_by(self, amount: U32) -> None:
        self.count += amount
        caller = get_caller()
        self.increments[caller] = self.increments.get(caller, 0) + amount

    @entry_point
    @require_unpaused
    def increment(self) -> None:
        self._increment_by(1)

    @entry_point
    @require_unpaused
    def increment_by(self, amount: U32) -> None:
        self._increment_by(amount)

    @entry_point
    def get(self) -> U32:
        return self.count

    @entry_point
    def get_increments(self, owner: AccountHash) -> U32:
        return self.increments.get(owner, 0)
  1. Declare storage. count is a named-key value. increments is a typed dictionary; _account_key turns an account hash into its dictionary key.
  2. Initialize once. The installer constructs Counter(initial). super().__init__ passes the initial count through inherited state setup; later calls bind stored values without rerunning initialization.
  3. Write both totals. _increment_by updates the total, gets the current caller, then adds the amount to that caller’s tally. .get(caller, 0) starts a new tally at zero.
  4. Guard writes, allow reads. require_unpaused protects the mutating entry points. get and get_increments remain callable while paused.

See the complete Counter source and installer ↗ and the Ownable and Pausable walkthrough ↗. Direct dictionary indexing of an absent account raises KeyError; the getter uses .get(..., 0) to return zero.

03DESCRIBE THE WIRE

Annotations are your ABI.

U32 arrives as a Python integer. A bool return is encoded as Casper Bool. Use Optional[T] for a nullable value and OptionalArg[T] when the argument may be absent entirely.

PYTHON ANNOTATIONamount: U32

Caller supplies a Casper U32; your method receives an int.

RETURN ANNOTATION-> bool

Casthon serializes the returned Python bool.

OPTIONAL PRESENCEOptionalArg[T]

Distinguishes an omitted argument from a supplied value.

nullable and missing arguments
from typing import Optional
from casthon import MISSING, OptionalArg, U32, export

@export
def describe(amount: OptionalArg[Optional[U32]] = MISSING) -> str:
    if amount is MISSING:
        return "absent"
    if amount is None:
        return "explicit None"
    return str(amount)
Expected values

Omitted argument → "absent" · encoded Option::None → "explicit None" · U32 value 5 → "5".

04CREATE THE PACKAGE

Installation stays explicit.

The exported top-level call creates a package, adds a contract version, and stores the resulting hashes. Building Wasm alone does not run this installer.

contracts/flipper.py · installer excerpt
installed = named_keys.reference("flipper", ContractHash)
installed_package = named_keys.reference("flipper_package", ContractPackageHash)
installed_access = named_keys.reference("flipper_access", URef[None])

@export
def call(initial: bool = False) -> None:
    if installed.name in named_keys:
        raise InvalidArgument()
    package, access = storage.create_contract_package_at_hash()
    contract, _ = package.add_contract_version(Flipper(value=initial))
    installed.set(contract)
    installed_package.set(package)
    installed_access.set(access)

05HANDLE OUTCOMES

Catch, clean up, or revert.

When a host API returns an error status, Casthon raises a Python ApiError subclass. You can catch it and recover. An uncaught error, including an ordinary Python exception, reverts the invocation and rolls back its state changes.

HOST API ERRORApiError

MissingKey, InvalidArgument, and UserError are catchable by except Exception. Unknown host codes remain ApiError(code).

EXPLICIT FAILUREruntime.revert(code)

Raises Revert, a BaseException. It bypasses except Exception, runs finally, and rolls back if it escapes.

EXPLICIT RETURNruntime.ret(value)

Serializes a CLValue and raises Ret, also a BaseException. It runs finally before returning successfully.

Follow one entry point through every path.

The repository’s Hello.greet catches an empty-name ValueError. A long name raises UserError(1), which that handler does not catch. In all three paths, the finally block runs before the result reaches Casper.

contracts/hello.py · complete greet method
from casthon import U32, UserError
from casthon.contract_api.runtime import named_keys
from casthon.contracts import Contract, entry_point, export_contract

@export_contract
class Hello(Contract):
    calls: U32 = named_keys.property()

    @entry_point
    def greet(self, name: str) -> str:
        try:
            name = name.strip()
            if not name:
                raise ValueError("Empty name")
            if len(name) > 64:
                raise UserError(1)
            return f"Hello, {name}!"
        except ValueError:
            return "Hello, stranger!"
        finally:
            self.calls += 1
            print("Greeting finished")
Valid name" Ada " returns "Hello, Ada!". The cleanup increment commits.
Empty nameValueError is caught, the fallback returns, and the increment commits.
Name over 64 charactersUserError(1) escapes. finally runs, then the invocation reverts and the increment rolls back.

The print("Greeting finished") line is useful while debugging. See the captured casthon test run and debug versus release behavior ↗.

Cleanup follows the final outcome

Normal return, runtime.ret, and runtime.revert all run applicable finally blocks. Writes from finally commit only if the invocation succeeds. You can explicitly catch Ret or Revert, but except Exception leaves both signals alone. A return or new exception in finally can replace the pending result, so keep cleanup free of outcome-changing control flow. Engine traps that do not return an API status still terminate execution.

See Hello’s installer ↗, its three-path test ↗, and the full exception reference ↗.

Give events a record, an entry point, and a topic.

An event is a typed record. emit encodes a plain Event as Bytesrepr by default and sends its binary payload to the "events" topic. Select JSON explicitly when a text payload is useful. Register the topic when installing the contract.

complete native-message contract pattern
from casthon import Event, Json, emit, export
from casthon.contract_api import storage
from casthon.contract_api.runtime import named_keys
from casthon.contracts import Contract, entry_point, export_contract

class Greeted(Event):
    name: str

@export_contract
class Greeter(Contract):
    @entry_point
    def greet(self, name: str) -> None:
        emit(Greeted(name))

    @entry_point
    def greet_json(self, name: str) -> None:
        emit(Greeted(name), encoder=Json.to_message)

@export
def call() -> None:
    package, access = storage.create_contract_package_at_hash()
    contract, _ = package.add_contract_version(
        Greeter(), message_topics=("events",)
    )
    named_keys["greeter"] = contract
    named_keys["greeter_package"] = package
    named_keys["greeter_access"] = access
Default: Bytesreprgreet("Ada") sends example payload 03 00 00 00 41 64 61: a four-byte string length, then UTF-8 text.
Optional: JSONgreet_json("Ada") sends example message string {"name":"Ada"}.
Other formats and failures

Inherit Json to make JSON the default for a record, or use JsonBytes for UTF-8 JSON bytes. A malformed record or encoder failure raises an ordinary catchable Python exception. Delivery uses the host API, so a host error arrives as ApiError. For a different topic, register it and call emit(event, topic="audit"). CES also accepts plain event records and encodes their fields as Bytesrepr. The full events reference ↗ covers encoder selection and CES.

06HASH A KNOWN IDENTIFIER

Compute the hash before the contract runs.

const_blake2b produces a 32-byte BLAKE2b-256 digest. It accepts a literal string (encoded as UTF-8) or bytes. Casthon replaces the call with literal bytes before compiling MicroPython bytecode.

Fixed role identifier
from casthon import const_blake2b

MINTER_ROLE = const_blake2b("MINTER_ROLE")
Native testsPython computes the same digest with hashlib, without a Casper host.
Compiled contractThe digest is a bytes object in the MicroPython constant table. An inline call becomes LOAD_CONST_OBJ.
Literal arguments only

Import at module scope. One positional string or bytes literal is required; dynamic inputs, function-valued references, and shadowed imports fail at build time. This precomputes the digest but does not make globals immutable. For runtime input, use runtime.blake2b(data). See the full reference and bytecode checks ↗.
