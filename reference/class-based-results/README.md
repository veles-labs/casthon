# Archived class-based experiment

These reports record the October 10, 2026 class-based Counter, CEP18 and inherited TestToken experiment. They describe the older artifacts and are retained as historical measurements. Current builds and validation reports live in `build/` and `results/`.

The old authoring source is backed up locally in `.cache/class-authoring-before-procedural.tar.gz`. The current `casthon.contracts` API has since reintroduced class contracts using ordinary constructors, annotated typed references, explicit package installation and root-only export selection. It does not use the earlier experiment's authoring framework.
